# 005 — Задачи

Формат: `T-XXX | задача | файлы | готово когда | размер | [P] | зависимости`.

- **Размер**: `S` ≤ ~80 строк диффа, `M` ≤ ~200, `L` ≤ ~300.
- **[P]** — не пересекается с другими по файлам и не ждёт их результата.
- **⚡** — критично для всплеска (SRS §1.6). В этом срезе таких нет: он не трогает
  ни приём, ни доставку. Единственное касание нагрузки — рост словарей в бюджете
  бандла, он покрыт гейтом T-019.
- **⚠** — требует решения продакта до старта (см. `spec.md`).
