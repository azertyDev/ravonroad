# 003 — Задачи

Формат: `T-XXX | задача | файлы | готово когда | размер | [P] | зависимости`.

- **Размер**: `S` ≤ ~80 строк диффа, `M` ≤ ~200, `L` ≤ ~300.
- **[P]** — не пересекается с другими по файлам и не ждёт их результата.
- **⚡** — критично для всплеска: десятки тысяч сессий чтения в час (SRS §1.6).
- **⚠** — требует решения владельца репозитория до старта (см. `spec.md`).
