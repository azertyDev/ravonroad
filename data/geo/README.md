# Геоданные

## tashkent-districts.geojson

Границы 12 районов города Ташкента. Используются для двух задач:

1. **Определение района заявки** — point-in-polygon по координатам пина. Геокодер не используется.
2. **Геозабор** — координаты, не попавшие ни в один полигон, отклоняются на входе формы.

| | |
|---|---|
| Источник | [opendata.tashkent.uz](https://opendata.tashkent.uz/data/136), датасет 136 «Тематический слой границы Ташкента» |
| Правообладатель | Хокимият г. Ташкента |
| Формат оригинала | Shapefile + KML, WGS84 (EPSG:4326) |
| Дата публикации оригинала | 2024-03-30 |
| Координаты | округлены до 6 знаков (~10 см) |

### Проверки при сборке

- 12 полигонов, площадь каждого совпадает с заявленной в датасете в пределах 0,1%
- суммарная площадь 43 885 га против 43 846 га в датасете 40 «Площадь Ташкента» — расхождение 0,09%
- сетка из 2940 точек по городу: **ни одна не попадает в два района одновременно**
- контрольные точки: Чиланзар и Юнусабад определяются верно, Самарканд и Чирчик отсекаются как «вне города»

### Важно

Мирзо-Улугбекский район состоит из **двух несвязанных частей** — у него есть эксклав. В геометрии это `MultiPolygon`. Данные OpenStreetMap приписывают этот эксклав Яшнабадскому району и расходятся с официальной площадью обоих районов примерно на 2000 га — поэтому OSM как источник отклонён.
