# Глоссарий предметной области

Единый язык проекта. Левая колонка — как говорим между собой, правая — как называем в коде.
Термина нет в таблице — сначала добавляем сюда, потом используем в коде.

## Основные сущности

| Термин | Идентификатор в коде | Значение |
| --- | --- | --- |
| Заявка | `Request` | Сообщение жителя об одной яме: фото, координаты, ориентир, необязательный контакт. Единица работы всей системы. |
| Яма | `pothole` | Физический дефект дорожного покрытия. Не является отдельной сущностью в БД — существует через заявку. |
| Житель | `reporter` | Человек, отправивший заявку. Не регистрируется, аккаунта не имеет, идентифицируется только необязательным контактом. |
| Волонтёр | `volunteer` | Участник бригады. Аккаунта на сайте не имеет, взаимодействует с системой только через Telegram-бот. |
| Модератор | `moderator` | Волонтёр, чей `telegram_user_id` входит в allowlist. Единственная роль, которой разрешено менять статус заявки. |
| Бригада | `crew` | Группа волонтёров, выезжающая на ремонт. В системе не моделируется — понятие организационное. |
| Пин | `location` | Точка на карте, выбранная жителем. Хранится как география PostGIS. Единственный источник координат: геокодер не используется. |
| Ориентир | `landmark` | Текстовое уточнение места от жителя («напротив дома 12», «у школы»). Заполняется вручную, адрес не вычисляется. |
| Фото «до» | `beforePhotos` | 1–3 снимка ямы от жителя. Прикладываются при создании заявки. |
| Фото «после» | `afterPhotos` | Снимки отремонтированного участка от волонтёра. Приходят через бот, переводят заявку в `DONE`. |
| Ссылка на публикацию | `publicationUrl` | Необязательная ссылка (обычно Instagram) на пост о выполненном ремонте. |
| Счётчик | `repairedCount` | Публичное число заявок в статусе `DONE`. Цель кампании — 10 000. |

## Статусы заявки

Статус меняет только модератор кнопкой в Telegram; исключение — переход в `DONE`,
который инициируется отправкой фото «после».

| Статус | Значение |
| --- | --- |
| `NEW` | Заявка принята системой, никто её ещё не смотрел. Начальное состояние. |
| `ACCEPTED` | Модератор подтвердил: яма настоящая, берём в работу. |
| `IN_PROGRESS` | Бригада выехала или работает на месте. |
| `DONE` | Яма отремонтирована, есть фото «после». Увеличивает счётчик. Терминальный. |
| `REJECTED` | Заявка отклонена: не яма, нечитаемое фото, мусорная отправка. Терминальный. |
| `DUPLICATE` | Про эту же яму уже есть заявка. Терминальный, счётчик не увеличивает. |
| `OUT_OF_SCOPE` | Дефект реальный, но бригаде не по силам или не по адресу (провал, теплотрасса, трасса вне города). Терминальный. |

## Термины процесса

| Термин | Значение |
| --- | --- |
| Карточка | Сообщение бота в группе волонтёров по одной заявке: фото, координаты, ориентир, inline-кнопки статусов. |
| Allowlist | Список `telegram_user_id` модераторов из переменной окружения. Заменяет собой всю авторизацию: таблицы пользователей, JWT и OTP в системе нет. |
| Петля | Полный цикл «заявка → карточка → ремонт → фото «после» → счётчик». Замкнута внутри системы: государственный орган в контур не входит. |
| Вертикальный срез | Единица поставки: одна фича, доведённая от формы на сайте до данных в БД и реакции бота. Описывается в `specs/NNN-slug/`. |
