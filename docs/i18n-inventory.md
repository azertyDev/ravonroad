# Инвентаризация строк интерфейса

Что где говорит и чем это проверено. Документ описывает **текущую вёрстку** (направление C),
а не макет: расхождение документа с кодом — ошибка документа (`CLAUDE.md` › Правила кода).

Эталон ключей — `apps/web/src/shared/i18n/uz.ts`. Русский словарь типизирован по нему
(`Record<UiKey, string>`), поэтому забытый перевод роняет `pnpm typecheck`, а не выходит
пустым местом на экране.

Модификаторные буквы в узбекских строках: `ʻ` U+02BB в `oʻ`/`gʻ`, `ʼ` U+02BC как
tutuq belgisi. Апострофы `'` U+0027 и `’` U+2019 запрещены и ловятся тестом.

## Экраны и их ключи

| Экран | Файл | Семейства ключей |
| --- | --- | --- |
| Каркас: шапка, подвал, переключатель языка | `shared/ui/layout/*`, `shared/i18n/LocaleSwitcher.tsx` | `app.*`, `header.*`, `locale.*`, `footer.*` |
| Главная: плакат, счётчик, разбивка, последняя закрытая | `routes/$locale/index.tsx`, `features/stats/*` | `home.*`, `map.tab`, `list.open`, `report.before`, `report.after` |
| Карта и её состояния | `features/report-map/*` | `map.*` |
| Список: таблица на ноутбуке, карточки на телефоне | `routes/$locale/reports/index.tsx`, `entities/report/Report{Row,Card}.tsx` | `list.*`, `map.empty.*`, `status.*` |
| Фильтры: строка и нижний лист | `features/report-filters/*` | `filters.*`, `status.*` |
| Форма заявки: пять шагов, окно поверх страницы | `features/report-form/*` | `form.*` |
| Подтверждение отправки | `features/report-form/Confirmation.tsx` | `form.done.*`, `report.copyLink`, `report.trackHint` |
| Страница заявки | `routes/$locale/reports/$number.tsx`, `entities/report/ReportSummary.tsx` | `report.*`, `status.*` |
| Страница отслеживания | `routes/$locale/z/$token.tsx` | `track.*`, `reason.*` |
| Состояния: загрузка, пусто, ошибка, офлайн | `shared/ui/state/*` | `state.*` |
| Неподдерживаемый браузер | `shared/ui/UnsupportedBrowser.tsx` | `unsupported.*` |
| Заголовок вкладки и описание страницы | `shared/lib/usePageMeta.ts` | `meta.*` |
| Ошибки API | `shared/api/client.ts` → `errorText()` | `Record<ErrorCode, string>` |

Доменные значения приходят с сервера кодами и переводятся клиентом (SRS §8.2):
статусы — `status.<STATUS>`, причины `REJECTED` и `OUT_OF_SCOPE` — `reason.<code>`.
Оба семейства собираются шаблоном, поэтому пропуск кода ломает `pnpm typecheck`:
тип словаря выведен из union-ов контракта.

**Единственное исключение — категории.** Их названия живут в БД (`category.name_uz`,
`name_ru`) и приходят ответом `/api/categories`: новая строка таблицы появляется в форме
без пересборки фронта (SRS §2.5). Ключей категорий в словарях нет и быть не должно.

**Названия районов** тоже приходят с сервера, а не из словаря. Их источник —
`data/geo/tashkent-districts.geojson`; сид миграции и таблица глоссария сверяются с ним
посимвольно (`apps/api/src/catalog/district-names.test.ts`).

**Свободный текст модератора** (причина «другое») не переводится и показывается как введён,
а рядом стоит переведённая поясняющая строка `track.reasonOther`.

## Чем это проверено

| Проверка | Где |
| --- | --- |
| Множества ключей `uz` и `ru` совпадают | `shared/i18n/messages.test.ts` |
| Пустых строк в словарях нет | там же |
| Узбекская латиница набрана U+02BB и U+02BC, а не ASCII-апострофом | там же |
| Мёртвых ключей нет: каждый ключ стоит хотя бы на одном экране | `shared/i18n/screens.test.ts` |
| В разметке экранов не осталось русских строк мимо словаря | там же |
| Названия районов совпадают в датасете, сиде и глоссарии | `apps/api/src/catalog/district-names.test.ts` |
| Каждому `ErrorCode` есть строка локали | `pnpm typecheck` (`Record<ErrorCode, string>`) |
| Ссылка переключателя языка держит путь и search-параметры | `shared/i18n/LocaleSwitcher.test.ts` |

## Что осталось за границей проверок

- **Вычитка носителем языка.** Тесты доказывают полноту и набор символов, но не то, что
  фраза звучит по-узбекски. Вынесено в `specs/005-i18n-a11y/spec.md` › «Требует решения
  продакта».
- **Узбекские строки, захардкоженные в разметке.** Тест ловит кириллицу; латиница
  в JSX-тексте от неё неотличима автоматически и остаётся предметом ревью.
- **Тексты Telegram-бота.** Одна локаль, группа волонтёров одна (вне рамок среза).
