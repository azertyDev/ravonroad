# Подложка карты — MapLibre GL и собственный экстракт PMTiles, а не коммерческий API

## Контекст и постановка задачи

ADR-0004 выбрал Яндекс Карты как виджет и тайлы, отказавшись от геокодера по
лицензионным причинам. При получении ключа выяснилось, что и оставшаяся часть
неприменима.

Консоль владельца показывает для JavaScript API **100 запросов в сутки**, страница
продукта называет 500. Порядок в любом случае — сотни. Условия бесплатного
использования при этом говорят прямо: регулярное превышение суточного лимита ведёт
к **блокировке доступа**, а не к счёту или деградации. Плюс обязательны видимый
логотип Яндекса и кнопка «Открыть в Картах» на нашем главном экране.

Сайт анонсируется аудитории Instagram-аккаунта бригады — около 127 000 подписчиков.
Один сторис при отклике в 3% даёт порядка 4 000 заходов за час. Карта — главный экран,
значит каждый заход это одна загрузка. Любой лимит в сотнях исчерпывается в первые
минуты после анонса, то есть ровно тогда, когда продукт нужен.

## Рассмотренные варианты

**Яндекс, платная лицензия.** 195 000 ₽/год плюс 390 ₽ за каждые 500 запросов сверх
лимита. Лучшие данные по Ташкенту и спутник. Отклонён: у волонтёрской кампании,
публично отказавшейся от денежных сборов (BRD §5), нет источника для такой статьи
расходов.

**2GIS Map Tiles API.** Проверен по документации: бесплатного тарифа нет вообще,
минимальный пакет 100 000 запросов за 8 000 ₽/мес, где один запрос — один векторный
тайл. Экран карты тянет 10–20 тайлов, то есть пакета хватает примерно на 6 000
просмотров. Отклонён.

**Mapbox.** 50 000 загрузок карты в месяц бесплатно, дальше $5 за 1000. Втрое щедрее
Яндекса и данные хорошие. Отклонён по характеру отказа: при превышении Mapbox
**выставляет счёт**, а не блокирует. Для проекта без выручки неограниченный счёт хуже
жёсткого лимита, и растёт он строго пропорционально успеху кампании. При 100 000
загрузок это ~$250/мес — порядка десяти бюджетов всей нашей инфраструктуры.

**MapLibre GL + собственный экстракт PMTiles.** Выбран.

## Решение

Подложка — статический файл `.pmtiles` с экстрактом Ташкента в том же объектном
хранилище, где лежат фотографии. Браузер читает его HTTP range-запросами; тайл-сервера,
ключей и счётчика запросов не существует.

Экстракт режется по **реальной границе города** из `data/geo/tashkent-districts.geojson`
(13 полигонов), а не по прямоугольнику. Размер — 19 МБ, зумы 0–15, данные OSM.

Стиль объявлен инлайном: 8 слоёв, без подписей, без спрайтов, без шрифтовых PBF.
Ни одного стороннего хоста сверх нашего бакета — иначе уход от коммерческого API
терял бы смысл. Цвета взяты из шкалы `asphalt` дизайн-системы, чтобы карта читалась
как часть интерфейса, а не как вставка чужого продукта.

## Последствия

**Хорошие.** Стоимость подложки — плата за хранение 19 МБ, порядка 7 сум в месяц
против 195 000 ₽ в год. Лимитов нет ни на загрузки, ни на тайлы. На критическом пути
не остаётся ни одного внешнего сервиса: карта не отвалится из-за исчерпанной квоты,
смены тарифа или недоступности чужого API. На проде тайлы поедут с того же хоста, что
и фотографии — по TAS-IX, ближе к пользователю, чем любой внешний CDN (аргумент про
TAS-IX отпал вместе с переездом прода за рубеж — см. Дополнение от 2026-08-19).

**Плохие.** Отсутствие шрифтовых PBF означает, что подписей нет нигде, включая слои
приложения: число внутри кластера слоем `symbol` нарисовать нечем. Поэтому маркеры
и кластеры публичной карты — элементы DOM поверх холста, а не слой карты; заодно они
получают фокус с клавиатуры и подпись для скринридера. У решения есть цена, которую
стоит знать заранее: MapLibre грузит тайлы источника только под слой, который на него
ссылается, поэтому источник с точками обязан иметь хотя бы невидимый слой — иначе он
исправно хранит данные, `querySourceFeatures` возвращает пустоту, и на карте нет ни
одного маркера, молча. Начинать со слоя `symbol`
не нужно — он упрётся в то же самое.
Нет спутниковой подложки. Нет подписей улиц — до отдельной задачи
по заливке глифов в бакет; в форме подачи это терпимо, потому что человек ставит пин
там, где стоит, но для просмотра карты в 003 названия улиц пригодятся. Качество данных
OSM по Ташкенту местами уступает яндексовскому. Данные обновляются только пересборкой
экстракта — имя файла содержит дату, обновление есть новый файл и новое значение
переменной.

**Нейтральные.** Прирост бандла 322,7 КБ br, весь ленивый: грузится только на маршруте
с картой и только при заданной переменной. Для сравнения, у яндексовой версии в бандле
было ноль, но JS API тянулся с их CDN в рантайме.

## Подтверждение

Экстракт собран, залит и проверен: range-запрос отдаёт `206`, CORS настроен, файл
кэшируется как `immutable`. Карта отрисована в браузере и в собранном образе, пин
ставится тапом, координаты уходят в форму. Состав слоёв тайлов проверен декодированием
архива, а не по документации.

## Дополнение от 2026-08-10: холодный старт

Проверка на развёрнутом стенде вскрыла то, чего не видно ни в dev-сервере, ни в
локальной сборке: **первый тайл появляется через 10–13 секунд после загрузки страницы.**

Замер трёх range-запросов к архиву прямо со страницы стенда:

| Запрос | Ответ | Время |
| --- | --- | --- |
| `bytes=0-16383` (заголовок) | `206` | 2219 мс |
| `bytes=16384-131071` (корневой каталог) | `206` | 810 мс |
| `bytes=2000000-…` (тайл) | `206` | 659 мс |

PMTiles ходит **последовательно**: заголовок → корневой каталог → лист → тайл. Четыре
круга по 0,6–2,2 с к чужому хосту, и только после этого начинается загрузка тайлов
экрана. Плюс ленивый чанк MapLibre, 280 КБ gzip. Ошибок при этом нет ни одной: карта
не сломана, она грузится, и всё это время житель видит пустой прямоугольник.

Отсюда два следствия, оба обязательны.

**Архив переезжает на наш собственный origin.** Тайлы отдаёт тот же nginx, что и
статику: `connect-src` в CSP сводится к `'self'`, из критического пути уходят чужой
DNS, чужой TLS-хендшейк и отдельное соединение, а на проде (тогда — AHOST, Ташкент)
четыре последовательных круга идут по TAS-IX вместо трансатлантического маршрута в
us-central1 (о судьбе этого довода — Дополнение от 2026-08-19). Переменная `VITE_MAP_PMTILES_URL` становится относительным путём
`/map/<файл>.pmtiles`; внешний адрес остаётся поддерживаемым значением, но перестаёт
быть значением по умолчанию.

**Пока тайлов нет, карта обязана показывать состояние загрузки.** Не пустой
контейнер: скелет или индикатор, снимаемый по первому отрисованному тайлу
(`map.on('idle')`, а не `load` — `load` срабатывает до прихода тайлов).

### Как это проверять

Два способа проверки дают ложноотрицательный результат, оба стоили команде времени:

- **`performance.getEntriesByType('resource')` не видит запросы MapLibre.** Тайлы
  грузит воркер, а его запросы в resource timing главного потока не попадают. Ноль
  записей к `.pmtiles` там будет и при полностью работающей карте.
- **Скриншот через 2–3 секунды после загрузки застаёт пустой прямоугольник.** Ждать
  нужно до 15 секунд. Отдельно: на общем скриншоте страницы отрисованная карта
  выглядит пустой — сжатие вытирает низкоконтрастные серые, смотреть увеличением
  фрагмента.

## Дополнение от 2026-08-19: прод уезжает за рубеж

Прод-хостом выбран Contabo (Германия) вместо ташкентского AHOST. Это отменяет **один
довод** решения, но не само решение.

**Что отпало.** TAS-IX. Тайлы больше не «ближе к пользователю, чем любой внешний CDN»:
для жителя Ташкента наш origin теперь такой же зарубежный хост, как чужой. Абзацы выше,
где TAS-IX назван преимуществом, читать как запись состояния на август 2026, а не как
действующий аргумент.

**Что осталось и стало важнее.** Собственный origin убирает из критического пути чужой
DNS, чужой TLS-хендшейк и отдельное соединение, а `connect-src` в CSP оставляет `self`.
При четырёх последовательных кругах PMTiles (заголовок → каталог → лист → тайл) экономия
одного хендшейка и одного разрешения имени — это уже не мелочь: круги стали дороже,
а не дешевле. Ровно поэтому относительный путь `/map/<файл>.pmtiles` остаётся значением
по умолчанию, а состояние загрузки карты — обязательным.

**Замер вместо догадки.** Из сети AS8193 Uzbektelekom, 19.08.2026, ICMP, 15 пакетов
без потерь: Contabo EU — **110 мс** RTT, GCE `us-central1` (нынешний стенд) — 196 мс,
ташкентские хосты — 6 мс. То есть переезд вдвое ближе текущего стенда и в 18 раз дальше
TAS-IX. Экстракт 19,1 МБ, лежащий сейчас в GCS с TTFB 509 мс, поедет с нашего edge
в Германии — по холодному старту карта **выигрывает**, а не проигрывает.

Если четыре круга всё равно дадут больше полутора секунд, следующий шаг известен
и от хостинга не зависит: слить заголовок и корневой каталог в сборку страницы, чтобы
первый запрос шёл сразу за листом.

## Примечания

`maplibre-gl` закреплён на v5. В v6 `addProtocol` не обслуживает запросы из главного
потока, а штатный обходной путь `importScriptInWorkers` экспериментален: его промис
не разрешается, и при неудачном импорте очередь актора встаёт целиком — стиль не
доходит до разбора, при этом в консоли нет ни строки. Возврат на v6 имеет смысл, когда
это API перестанет быть экспериментальным.

Запрет геокодера из ADR-0004 остаётся в силе и по своей причине: район вычисляет
сервер по нашим полигонам, адрес не хранится.
