# Подложка карты — MapLibre GL и собственный экстракт PMTiles, а не коммерческий API

## Контекст и постановка задачи

ADR-0004 выбрал Яндекс Карты как виджет и тайлы, отказавшись от геокодера по
лицензионным причинам. При получении ключа выяснилось, что и оставшаяся часть
неприменима.

Консоль владельца показывает для JavaScript API **100 запросов в сутки**, страница
продукта называет 500. Порядок в любом случае — сотни. Условия бесплатного
использования при этом говорят прямо: регулярное превышение суточного лимита ведёт
к **блокировке доступа**, а не к счёту или деградации. Плюс обязательны видимый
логотип Яндекса и кнопка «Открыть в Картах» на нашем главном экране.

Сайт анонсируется аудитории Instagram-аккаунта бригады — около 127 000 подписчиков.
Один сторис при отклике в 3% даёт порядка 4 000 заходов за час. Карта — главный экран,
значит каждый заход это одна загрузка. Любой лимит в сотнях исчерпывается в первые
минуты после анонса, то есть ровно тогда, когда продукт нужен.

## Рассмотренные варианты

**Яндекс, платная лицензия.** 195 000 ₽/год плюс 390 ₽ за каждые 500 запросов сверх
лимита. Лучшие данные по Ташкенту и спутник. Отклонён: у волонтёрской кампании,
публично отказавшейся от денежных сборов (BRD §5), нет источника для такой статьи
расходов.

**2GIS Map Tiles API.** Проверен по документации: бесплатного тарифа нет вообще,
минимальный пакет 100 000 запросов за 8 000 ₽/мес, где один запрос — один векторный
тайл. Экран карты тянет 10–20 тайлов, то есть пакета хватает примерно на 6 000
просмотров. Отклонён.

**Mapbox.** 50 000 загрузок карты в месяц бесплатно, дальше $5 за 1000. Втрое щедрее
Яндекса и данные хорошие. Отклонён по характеру отказа: при превышении Mapbox
**выставляет счёт**, а не блокирует. Для проекта без выручки неограниченный счёт хуже
жёсткого лимита, и растёт он строго пропорционально успеху кампании. При 100 000
загрузок это ~$250/мес — порядка десяти бюджетов всей нашей инфраструктуры.

**MapLibre GL + собственный экстракт PMTiles.** Выбран.

## Решение

Подложка — статический файл `.pmtiles` с экстрактом Ташкента в том же объектном
хранилище, где лежат фотографии. Браузер читает его HTTP range-запросами; тайл-сервера,
ключей и счётчика запросов не существует.

Экстракт режется по **реальной границе города** из `data/geo/tashkent-districts.geojson`
(13 полигонов), а не по прямоугольнику. Размер — 19 МБ, зумы 0–15, данные OSM.

Стиль объявлен инлайном: 8 слоёв, без подписей, без спрайтов, без шрифтовых PBF.
Ни одного стороннего хоста сверх нашего бакета — иначе уход от коммерческого API
терял бы смысл. Цвета взяты из шкалы `asphalt` дизайн-системы, чтобы карта читалась
как часть интерфейса, а не как вставка чужого продукта.

## Последствия

**Хорошие.** Стоимость подложки — плата за хранение 19 МБ, порядка 7 сум в месяц
против 195 000 ₽ в год. Лимитов нет ни на загрузки, ни на тайлы. На критическом пути
не остаётся ни одного внешнего сервиса: карта не отвалится из-за исчерпанной квоты,
смены тарифа или недоступности чужого API. На проде тайлы поедут с того же хоста, что
и фотографии — по TAS-IX, ближе к пользователю, чем любой внешний CDN.

**Плохие.** Нет спутниковой подложки. Нет подписей улиц — до отдельной задачи
по заливке глифов в бакет; в форме подачи это терпимо, потому что человек ставит пин
там, где стоит, но для просмотра карты в 003 названия улиц пригодятся. Качество данных
OSM по Ташкенту местами уступает яндексовскому. Данные обновляются только пересборкой
экстракта — имя файла содержит дату, обновление есть новый файл и новое значение
переменной.

**Нейтральные.** Прирост бандла 322,7 КБ br, весь ленивый: грузится только на маршруте
с картой и только при заданной переменной. Для сравнения, у яндексовой версии в бандле
было ноль, но JS API тянулся с их CDN в рантайме.

## Подтверждение

Экстракт собран, залит и проверен: range-запрос отдаёт `206`, CORS настроен, файл
кэшируется как `immutable`. Карта отрисована в браузере и в собранном образе, пин
ставится тапом, координаты уходят в форму. Состав слоёв тайлов проверен декодированием
архива, а не по документации.

## Примечания

`maplibre-gl` закреплён на v5. В v6 `addProtocol` не обслуживает запросы из главного
потока, а штатный обходной путь `importScriptInWorkers` экспериментален: его промис
не разрешается, и при неудачном импорте очередь актора встаёт целиком — стиль не
доходит до разбора, при этом в консоли нет ни строки. Возврат на v6 имеет смысл, когда
это API перестанет быть экспериментальным.

Запрет геокодера из ADR-0004 остаётся в силе и по своей причине: район вычисляет
сервер по нашим полигонам, адрес не хранится.
